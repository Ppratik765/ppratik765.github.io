### About This Repository (The Terminal Portfolio)
This repository houses the source code for my interactive, terminal-based web portfolio ([ppratik765.github.io](https://ppratik765.github.io/)).

#### Technical Architecture
- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Animation Engine**: GSAP (GreenSock) for high-performance timeline sequencing.
- **Visuals**: Native HTML5 `<canvas>` rendering for dynamic data flows and matrix overlays.
- **Interface**: Custom IIFE terminal logic bypassing standard DOM inputs to prevent layout shifts.

#### Local Deployment
To run this environment locally and inspect the code:
```bash
git clone https://github.com/Ppratik765/ppratik765.github.io.git
cd ppratik765.github.io
npx serve .
```
