### About This Repository (The Terminal Portfolio)
This repository houses the source code for my interactive, terminal-based web portfolio ([ppratik765.github.io](https://ppratik765.github.io/)).

#### Technical Architecture
- **Core**: Vanilla HTML5, CSS3, JavaScript (ES6+) — no build step.
- **Animation Engine**: GSAP + ScrollTrigger (self-hosted in `vendor/`, pinned) for timeline sequencing.
- **Visuals**: Native HTML5 `<canvas>` — a bespoke live visualiser on every project card.
- **Interface**: Custom terminal, a `Ctrl/⌘ + K` command palette, and a "stardust" cursor that morphs around controls and latches onto cards.
- **Performance**: the hero game iframe is skipped on small screens, reduced-motion and data-saver visitors, and unloaded when scrolled far away.
- **SEO**: canonical URLs, Open Graph / Twitter cards with generated 1200×630 images, JSON-LD (Person, WebSite, project index, per-project SoftwareApplication + breadcrumbs), sitemap, robots and web manifest.

#### Adding demo media to a project page
Drop a clip or screenshot named after the project into `data/media/` (e.g. `data/media/aerotwin.mp4`, `.webm`, `.webp`, `.png` or `.jpg`). The page shows it automatically; with no file present, nothing is rendered.

#### Local Deployment
To run this environment locally and inspect the code:
```bash
git clone https://github.com/Ppratik765/ppratik765.github.io.git
cd ppratik765.github.io
npx serve .
```
