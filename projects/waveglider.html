Waveglider Ocean

Domain Fluid Physics Simulation / WebGL
Core Stack WebGL, Three.js, GLSL, Gerstner Math
Performance GPU-based vertex displacements at 60 FPS
View Code on GitHub Live Demo

Purpose & Necessity

Rendering realistic fluid surfaces in browsers requires heavy floating-point calculation. Doing this on the CPU degrades browser responsiveness and kills framerates. Waveglider delegates these displacement calculations entirely to the GPU by translating Gerstner wave vector equations into vertex shaders, keeping CPU resources clear for logistical or layout tasks.

Key Technical Implementation

A Gerstner wave model defines wave height, sharpness, and directional movement vectors using parameter matrices. Dynamic foam particles are spawned at steep crests inside fragment shaders. To optimize rendering boundaries, a level-of-detail (LOD) grid decreases geometry density at further distances from the camera plane.
