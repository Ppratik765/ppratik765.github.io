Beyond the Apex

Domain Data Ingestion / Race Telemetry Analytics
Core Stack Python, FastF1, Pandas, Canvas 2D, D3.js
Data Metrics Delta speeds, steering angles, gear transitions
View Code on GitHub Live Demo

Purpose & Necessity

Formula 1 data feeds are highly dense, timing-critical, and complex. Combining multiple driver metrics (steering angle, throttle/brake overlays, velocity vectors) to analyze overtaking opportunities or pit wall strategy is challenging without clear spatial rendering. Beyond the Apex serves as a high-performance telemetry dashboard, ingesting and aligning fast-moving API packages into legible, interactive data charts.

Key Technical Implementation

The engine ingests data from python-wrapped FastF1 APIs, indexing frames using Pandas arrays. Clean Canvas 2D grids render line sweep overlays when selecting driver channels, tracking metrics like braking points and throttle inputs across coordinates of specific F1 circuits.
