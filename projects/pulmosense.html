PulmoSense

Domain Healthcare Diagnostics / Deep Learning
Core Stack Python, PyTorch, CNN architectures, Grad-CAM
Data Layer Chest X-Ray radiographs (pneumonia / healthy classification)
View Code on GitHub

Purpose & Necessity

Diagnosing lung diseases quickly and accurately from chest radiographs requires deep specialist reviews. In rural or under-resourced medical facilities, clinical radiograph backlogs delay triage times. PulmoSense provides automated assistance by feeding scan files to a high-accuracy Convolutional Neural Network (CNN) to predict classifications in seconds.

Key Technical Implementation

PulmoSense employs PyTorch to train deep convolutional architectures (ResNet & Custom CNN models). Visual explanations are mapped using Grad-CAM, generating heatmaps highlighting anomalous areas directly onto the predicted output matrix to assist clinicians in their review workflow.
