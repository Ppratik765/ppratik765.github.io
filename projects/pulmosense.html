PulmoSense

Domain Healthcare Diagnostics / Deep Learning
Core Stack Python, MobileNetV3, TensorFlow Lite, Kotlin (Jetpack Compose)
Data Layer ICBHI respiratory sound recordings, 8 diagnostic classes
View Code on GitHub
96.99% reported accuracy across 8 respiratory classes
10 MB quantised TFLite model, fully offline
97.01% reported macro F1-score

Purpose & Necessity

Respiratory conditions such as COPD, asthma and pneumonia are hard to screen for where specialist equipment and pulmonologists are scarce, and stethoscope auscultation is subjective. PulmoSense moves the screening onto the phone: it works fully offline, so patient audio never leaves the device and rural clinics without connectivity can still use it.

Key Technical Implementation

The app guides the user through a 20-second breathing exercise while recording 16 kHz audio, splits it into four overlapping 5-second chunks, and converts each into a 128-band log-Mel spectrogram (a 128 x 157 x 3 tensor). A quantised MobileNetV3 model in TensorFlow Lite classifies every chunk and the softmax outputs are averaged into a single diagnostic confidence.

The model was fine-tuned on the ICBHI respiratory sound dataset with class weights capped at 5.0 to counter its heavy COPD imbalance, and reports 96.99% accuracy, 97.11% macro precision, 96.91% recall and 97.01% F1 on a held-out set. The Jetpack Compose app packages the roughly 10 MB model for fully offline use.
