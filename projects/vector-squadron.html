Vector Squadron

Domain 3D Space Flight Simulation / Game
Core Stack Three.js, GLSL, WebGL, Web Audio API
Architecture Static client-side modular script pipelines
View Code on GitHub Live Demo
Rust → WASM 6-DOF flight physics and hit detection
60 FPS target on desktop and integrated mobile GPUs
GLSL custom shaders for the space scene

Purpose & Necessity

Vector Squadron is built to push the boundary of web-based GPU rendering and game loops. High-fidelity rendering in the browser traditionally requires bulky, opinionated engine assets. This project explores building a light, responsive game engine using vanilla Three.js coupled with custom vertex and fragment shaders (GLSL) to execute lightning-fast space flight simulation without sacrificing performance or visual aesthetics.

Key Technical Implementation

Autonomous pathfinding coordinates and autopilot algorithms allow drones and support ships to patrol wireframe grid paths. A custom GPU physics solver handles projectile collisions, particle explosion expansions, and collision bounds checks inside browser threads. Sound is spatialized using the native Web Audio API, shifting frequency and panning based on camera vectors.
