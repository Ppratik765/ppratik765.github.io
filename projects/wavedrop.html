WaveDrop

3 transfer tiers: optical, WebRTC, native Android

Purpose & Necessity

Every mainstream way to move a file, from Bluetooth to AirDrop to local Wi-Fi, opens a radio or network attack surface. WaveDrop shows that a file can cross a physical air gap using only light: one screen displays, another camera reads.

Key Technical Implementation

Files are split into droplets with Luby Transform erasure coding, so the receiver can rebuild the whole file from any sufficiently large subset of frames. Dropped frames, blur and frame-rate mismatch do not matter and no acknowledgement channel is needed. Each droplet carries a 20-byte header, and the payload is verified with an embedded SHA-256 digest before it reaches the filesystem.

For bigger transfers, the two devices exchange compressed WebRTC session descriptions optically and then switch to a direct peer-to-peer data channel with no signalling server. Decoding runs in WebAssembly across a Web Worker pool, and the native Kotlin Android app adds CameraX scanning and direct downloads. The project ships with 80 passing unit tests.
