DamageLens

Domain Disaster Response / Geospatial Deep Learning
Core Stack PyTorch, Next.js 14, React-Leaflet, GeoPandas, Shapely
Data Layer xBD post-disaster satellite imagery, geo-referenced pre/post pairs
View Code on GitHub Live Demo
4 building damage severity tiers
xBD post-disaster satellite imagery dataset
2 images per site: before and after, swipe to compare

Purpose & Necessity

In the hours after a disaster, responders need to know which buildings are safe, which are damaged, and which are destroyed — long before ground teams can physically reach every site. DamageLens automates that triage from satellite imagery alone: given a pre-disaster and post-disaster image pair, it localizes every building and classifies its damage into four severity tiers, then surfaces the result on an interactive map instead of a raw model output.

Key Technical Implementation

The core model is a Siamese U-Net (Siam-UNet-Diff) with a shared-weight ResNet-34 encoder that extracts features from the pre- and post-disaster images independently, then differences and concatenates them through the decoder. Two heads branch off the shared features: a binary localization head that segments building footprints, and a classification head that scores each one across the xBD damage scale — none, minor, major, or destroyed. The training pipeline (PyTorch, Albumentations, GeoPandas) exports a standardized manifest, GeoJSON, and paired PNGs to a strict data contract, so the model side and the frontend never need to know about each other's internals. That frontend is a Next.js 14 app with an interactive before/after swipe comparison built on React-Leaflet — sliding across a disaster site reveals the classified damage polygons, color-coded by tier, over the raw imagery, alongside aggregate per-site impact statistics.
