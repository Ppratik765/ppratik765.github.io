F1 Monte Carlo Simulator

Domain Motorsport Analytics / Monte Carlo Simulation
Core Stack Python, NumPy, pandas, FastF1, Matplotlib, Seaborn
Output Win, podium, points and DNF probabilities per driver
View Code on GitHub
50,000 default Monte Carlo iterations per race
6 2026 Grand Prix forecasts published
5 analytical chart types generated
NumPy vectorized lap-by-lap race engine

Purpose & Necessity

A single prediction of a Grand Prix is nearly worthless; the interesting question is how likely each outcome is. This engine replays a race weekend tens of thousands of times with realistic randomness, turning practice and qualifying data into full probability distributions rather than one guess.

Key Technical Implementation

A data pipeline pulls and caches timing data from FastF1, a qualifying engine builds the grid, and a vectorized NumPy race engine simulates the race lap by lap. Sub-models cover empirically bootstrapped DNFs, setup variance and unscheduled stops, lap-to-lap pace variance, midfield first-lap collision risk, dirty air with DRS tow, and 2026 battery-drain superclipping.

The backtester runs the Monte Carlo loop (50,000 iterations by default) and writes aggregated positional frequencies, which a visualizer turns into five chart types: stacked win/podium/points/DNF bars, tiered finish joyplots, expected points, net position change and DNF risk. Pre-race forecasts for six 2026 Grands Prix are published in the repository.
